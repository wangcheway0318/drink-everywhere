# 🧋 附近飲料店查找網頁

用 Google Maps Places API 搜尋附近飲料店，支援手機版與電腦版。

## 功能
- 📍 自動定位 / 手動搜尋地址
- 🔴 搜尋半徑圓圈（0.5 ~ 5 km）
- 🧋 地圖上顯示珍奶圖標與店名
- 🫧 品牌泡泡分佈圖
- 📋 店家清單（依距離排列）
- 🕐 點選店家查看營業時間、評分、電話
- 🍵 AI 自動產生菜單
- 📝 點餐清單（含甜度、冰量、總價計算）

## 部署說明
1. 將此資料夾上傳到 GitHub
2. 在 Netlify 連結 GitHub repo
3. 部署設定：Publish directory = `.`（根目錄）
4. 完成！
